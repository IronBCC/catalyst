# Catalyst Causal-Chain Explorer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Web tool that turns a hypothesized event into an auditable causal graph of downstream events and market variables, lets the user explore a "multiverse" (pin, slide, branch, stress-test) with live recomputation and Monte-Carlo, and ends in a tradeable thesis card.

**Architecture:** One Next.js 16 app on Vercel. The browser does all math (noisy-OR propagation, Monte-Carlo, sensitivity, dagre layout). The server is four LLM route handlers (OpenRouter via AI SDK 7, streamed structured JSON) plus two proxies (Polymarket search, Yahoo quotes). No database; localStorage plus JSON export.

**Tech Stack:** Next.js 16.3, React 19.2, TypeScript, Tailwind 4, @xyflow/react 12.11, @dagrejs/dagre 3.1, zustand 5, zod 4.5, ai 7.0 + @ai-sdk/react + @openrouter/ai-sdk-provider 3.0, vitest 4, @playwright/test 1.62. Node 22.

**Spec:** `docs/superpowers/specs/2026-09-01-catalyst-design.md`

## Global Constraints
- Provider: OpenRouter only. Env `OPENROUTER_API_KEY`, `OPENROUTER_MODEL` default `openai/gpt-5.6-luna`. Settings `reasoning.effort: "low"`, `provider.require_parameters: true`. One model for all calls.
- The LLM never sets final numbers shown in the thesis; it parameterizes the graph once and writes prose. All displayed probabilities and moves come from `src/lib/engine`.
- Interventions are do-operator: downstream only, no upstream inference. UI copy says "intervention".
- Deterministic engine: same graph + edits + seed → identical output. Monte-Carlo is seeded.
- No `.optional()` in LLM-facing zod schemas (strict json_schema needs all keys); use `.nullable()`.
- Dark monospace aesthetic (JetBrains Mono), gold titles, green values, red adverse deltas. Load the `frontend-design` skill before styling and the `dataviz` skill before any chart (histogram, tornado, strip).

### Task 3: Propagation + audit
**Files:** Create `src/lib/engine/propagate.ts`, `tests/propagate.test.ts`.
**Consumes:** Task 1 types, Task 2 `toposort`.
**Produces:**
```ts
export type Fixed = { pins: Map<string, boolean>; overrides: Map<string, number> };
export type AuditTerm = { label: string; formula: string; value: number };
export type EventResult = { p: number; fixed: "pin" | "override" | null; terms: AuditTerm[] };
export type NumericResult = { move: number; level: number | null; fixed: "override" | null; terms: AuditTerm[] };
export type Computed = { order: string[]; events: Map<string, EventResult>; numerics: Map<string, NumericResult> };

export function propagate(graph: Graph, fixed: Fixed): Computed;

```
Core:
```ts
// event
let p = 1 - (1 - base) * promote.reduce((acc, e) => acc * (1 - e.strength * q(e)), 1);
p *= inhibit.reduce((acc, e) => acc * (1 - e.strength * q(e)), 1);
// numeric
move = baselineMove + Σ en: p_source * impact + Σ nn: beta * move_source;
level = current == null ? null : current * (1 + move / 100);
```
- [ ] Tests (hand-computed): single promote edge base .2, s .7, parent p .85 → p = 1 − 0.8·(1 − 0.595) = 0.676; add inhibitor s .5 parent .3 → ×0.85 = 0.5746; pinned child ignores parents; override sets the exact value; numeric chain: event p .5 impact −10 → move −5; nn beta 0.6 → −3; level with current 100 → 97; `ne` edge threshold 70 below width 5, level 65 → q = sigmoid(1) = 0.731; terms non-empty with the right count.
- [ ] Implement, pass, commit `feat(engine): expectation propagation with audit terms`.
