# README media

Regenerated by `node scripts/capture-media.mjs` against a dev server on :3000, which writes
the PNGs here and a webm beside them.

The two derived files come from that webm:

```sh
V=/tmp/catalyst-capture/*.webm

ffmpeg -y -i $V -vf "scale=1440:-2" -c:v libx264 -pix_fmt yuv420p -crf 26 \
  -movflags +faststart docs/media/demo.mp4

ffmpeg -y -i $V -vf "fps=8,scale=860:-1:flags=lanczos,split[s0][s1];\
[s0]palettegen=max_colors=96[p];[s1][p]paletteuse=dither=bayer:bayer_scale=4" \
  -loop 0 docs/media/demo.gif
```

The GIF is what the README embeds — GitHub renders an animated GIF inline but only links an
MP4 committed to a repository. The MP4 is kept for anyone who wants the sharper version.
